# Saber hilt

The textured hilt from [demo-05_inputxr](../../../../demo-05_inputxr), using its
existing mesh, PBR material and textures. A parent node turns it upright for
GLTFXR's model viewer. The plasma blade and controller buttons aren't included

The original model is [Kyle Katarn's lightsaber low poly textured by Al](https://sketchfab.com/3d-models/kyle-katarns-lightsaber-low-poly-textured-40ff644dad724523a9983149b3b284c0).
The retained [licence notice](LICENSE.md) records CC BY-NC-SA 4.0 and the inputxr
modifications. This copy adds the upright parent transform described above.
